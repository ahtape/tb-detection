# Final Project PCD - Tuberculosis Detection

Dataset diambil dari [TB Chest Radiography Database](https://www.kaggle.com/datasets/tawsifurrahman/tuberculosis-tb-chest-xray-dataset)

## Usage

### Using Notebook

1. Put your test image in test/data folder
2. Open detection/test.ipynb
3. run the cell

### Using Web UI
1. Put your test image in test/data folder
2. run main.py
3. Open your browser and go to localhost:5050
